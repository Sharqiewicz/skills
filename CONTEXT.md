# skills

A personal collection of Claude Code skills, and the curation of every other skill installed alongside it.

## Language

**Noise**:
The cost of a skill that is installed but not earning its place. It has two sides: the model reads its description in every session and may pick it wrongly, and the human scans past it when choosing a command.
_Avoid_: clutter, bloat

**Remove**:
Take a skill out entirely: uninstall it if it is external, delete it if it lives in this repo. It never means making a skill manual-only or limiting it to one project.
_Avoid_: disable, scope, hide
